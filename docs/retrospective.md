# Протокол командної ретроспективи проєкту «PyLearn» (Start, Stop, Continue)

## 1. Загальний огляд
Команда CodeCrafters підсумувала результати розробки тренажера за методологією Scrum.

## 2. Категорії аналізу:
- **START (Почати):** Писати інтеграційні E2E тести для перевірки поведінки інтерфейсу.
- **STOP (Припинити):** Робити великі неатомарні коміти, залишати документацію на останній момент.
- **CONTINUE (Продовжити):** Регулярні код-рев'ю, Feature Branch Workflow, автоматизацію CI в GitHub Actions.
