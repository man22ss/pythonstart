# Реєстр звітів про дефекти та журнал Code Review у тренажері «PyLearn»

## Звіт про дефект BUG-01: Ділення на нуль при розрахунку результату
- **Серйозність:** Medium / **Пріоритет:** High
- **Компонент:** `src/js/quiz.js` -> `calculateScorePercentage()`
- **Опис:** Якщо загальна кількість питань total дорівнювала 0, функція повертала `NaN%`.
- **Виправлення:** Додано захисну перевірку `if (!total || total <= 0) return 0;`.
- **Статус:** Закрито (Verified).

## Звіт про дефект BUG-02: Помилка перевірки через зайві пробіли
- **Серйозність:** High / **Пріоритет:** High
- **Компонент:** `src/js/quiz.js` -> `validateAnswer()`
- **Опис:** Якщо користувач вводив відповідь із пробілом на початку, зараховувалася помилка.
- **Виправлення:** Застосовано `String(selected).trim().toLowerCase()`.
