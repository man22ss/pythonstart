# Архітектурна специфікація навчального тренажера «PyLearn»

## 1. Модульна структура (ES6 Modules)
- `state.js` - централізоване керування станом (поточна тема, індекс питання, бали).
- `topics.js` - завантаження та парсинг навчальних матеріалів.
- `theory.js` - рендеринг конспекту та блоків коду.
- `quiz.js` - логіка перевірки відповідей та підрахунку результатів.
- `ui.js` - робота з DOM, обробка кліків та перемикання екранів.
- `app.js` - головна точка входу.
