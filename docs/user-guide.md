# Інструкція користувача навчального тренажера «PyLearn»

## 1. Загальні відомості
Тренажер «PyLearn» призначений для вивчення основ програмування мовою Python учнями 8-9 класів. Застосунок працює онлайн без встановлення середовищ програмування.

## 2. Як користуватися
1. Відкрийте посилання на сайт: `https://man22ss.github.io/pythonstart/`.
2. Оберіть тему в каталозі («Змінні», «Арифметика», «Умови», «Цикли»).
3. Прочитайте стислий конспект та перейдіть до тесту.
4. Дайте відповіді на запитання та отримайте оцінку.
