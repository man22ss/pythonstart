# Специфікація вимог до навчального тренажера «PyLearn»

## 1. Загальний опис системи
Навчальний тренажер «PyLearn» створений для наочного засвоєння синтаксису мови Python учнями 8-9 класів. Застосунок функціонує безпосередньо у веб-браузері без встановлення стороннього ПЗ.

## 2. Функціональні вимоги (Functional Requirements)
- **FR-01:** Каталог із 4 ключових тем («Змінні та типи», «Арифметика», «Умови if-else», «Цикли for/while»).
- **FR-02:** Теоретичний конспект з акцентом на підсвічений синтаксис коду.
- **FR-03:** Інтерактивний тест із 4 варіантами відповідей та миттєвим зворотним зв'язком.
- **FR-04:** Збереження прогресу в `localStorage` браузера.
- **FR-05:** Відмовостійка робота в режимі Offline (завантаження локального контенту).

## 3. Нефункціональні вимоги (Non-Functional Requirements)
- **NFR-01 (Продуктивність):** Час початкового завантаження сторінки до 1.5 секунди.
- **NFR-02 (Адаптивність):** Коректне відображення на мобільних пристроях від 360px до 4K.
- **NFR-03 (Доступність):** Контрастність тексту за стандартом WCAG AA.
- **NFR-04 (Надійність):** Захист від збоїв мережі та коректна обробка винятків при розрахунку результату.

## 4. Пріоритизація вимог за методом MoSCoW
| ID | Вимога | Пріоритет за MoSCoW |
| :--- | :--- | :--- |
| US-01 | Навігація каталогом навчальних модулів | Must have |
| US-02 | Читання теорії з синтаксису Python | Must have |
| US-03 | Проходження тестів із вибором варіанта | Must have |
