# Специфікація UI/UX дизайну тренажера «PyLearn»

## 1. Дизайн-концепція та стилістика
- **Стиль:** Мінімалістичний інтерфейс із темною темою та смарагдовими акцентами для зниження навантаження на зір учнів.
- **Кольорова палітра:**
  - Головний фон: `#0f172a` (глибокий сланцевий)
  - Колір карток: `#1e293b` (темно-сірий)
  - Акцентний колір (успіх, кнопки): `#10b981` (смарагдовий)
  - Помилка: `#ef4444` (червоний)
  - Текст: `#f8fafc` (білий) / `#94a3b8` (вторинний)
- **Типографіка:** Шрифт Arial / Inter, базовий розмір 16px, заголовки 24-32px.

## 2. Структура сторінок (Sitemap)
1. **Головна (Home):**
   - Логотип `PyLearn` та індикатор загального прогресу.
   - Картки 4 тем курсу із кнопками початку навчання.
2. **Екран теми (Topic View):**
   - Теоретична довідка з блоком коду.
   - Кнопка переходу до вправ.
3. **Екран вікторини (Quiz View):**
   - Питання, блок з кодом, 4 варіанти відповідей.
   - Кнопка підтвердження та переходу до наступного завдання.
4. **Підсумковий екран (Result View):**
   - Набрані бали, відсоток успішності, кнопка повернення до каталогу.
