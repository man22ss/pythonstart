# Журнал використання генеративного ШІ у проєкті «PyLearn»

## 1. Запит (Prompt)
Сформульовано промпт для генерації асинхронного клієнта REST API з підтримкою автономного режиму.

```text
Роль: Senior JavaScript Developer.
Завдання: Напиши модуль api.js для веб-тренажера з мови Python.
Вимоги:
1. Запит через fetch() з async/await до публічного API.
2. Обробка помилок try...catch.
3. Обов'язковий резервний об'єкт FALLBACK_TIP при відсутності мережі.
```

## 2. Результат інспекції та верифікації
- ШІ згенерував базову функцію `fetchDailyTip()`.
- Внесено ручну правку: додано параметр `{ cache: 'no-store' }`, щоб уникнути кешування застарілих порад браузером.
- Проведено тестування в режимі Offline у вкладці DevTools Network. Модуль стабільно повертає локальний fallback без помилок у консолі.
