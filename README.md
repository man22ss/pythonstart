# PyLearn - Навчальний тренажер із мови Python

**Освітній проєкт команди CodeCrafters**  
Розроблено в межах навчальної дисципліни «Командна розробка програмних проєктів» (спеціальність 014.09 Середня освіта).

---

## 1. Паспорт проєкту
- **Назва:** PyLearn (Інтерактивний тренажер із базового синтаксису Python)
- **Команда:** CodeCrafters (Група СОІ-23-1)
- **Цільова аудиторія:** Учні 8-9 класів ЗЗСО та студенти коледжів
- **Склад команди та ролі:**
  - **Мансур Мухаммад** - Технічний спеціаліст (Developer / Розробник)
  - Координатор проєкту (Team Lead / Scrum Master)
  - Аналітик вимог (Product Owner)
  - Дизайнер інтерфейсу (UI/UX Designer)
  - Тестувальник (QA Engineer)

---

## 2. Проблема та рішення
- **Проблема:** Складність першого знайомства з текстовим кодом, синтаксичні помилки та відсутність швидкої перевірки знань у школярів.
- **Рішення:** Легкий веб-застосунок у браузері з короткою теорією, наочними прикладами та інтерактивними тестовими завданнями.

---

## 3. Технологічний стек
- Python 3.12 (консольні прототипи завдань)
- HTML5, CSS3 (адаптивний інтерфейс)
- JavaScript (ES6 модулі, збереження прогресу в LocalStorage)
- Vitest (модульне тестування)
- GitHub Actions (автоматизований CI/CD конвеєр)
- GitHub Pages (хостинг)
